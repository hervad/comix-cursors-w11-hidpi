## Changes from upstream

- Rendered from upstream's SVG templates (`svg/RightHanded`, `svg/LeftHanded`; 500 px canvas) at every Windows cursor
  size, no resampling. Colours, outline width and opacity come from upstream's `ComixCursorsConfigs` exactly as
  upstream's `bin/build-cursors` applies them (same substitutions, same order): the variants in `theme.toml` are
  generated by `tools/variants_from_configs.py`, and all 720 recoloured SVGs (48 variants x 15 cursors) were checked
  byte-identical to upstream's own substitution function.
- All 48 themes from the gnome-look page: 6 colours x Regular/Slim x translucent/Opaque x right-/left-handed.
- Drop shadow kept as upstream draws it (a faint blurred shadow, rendered with resvg). v0.1.0 left it out (toolkit
  ADR-14); without it the Black variants' white outline vanished on light backgrounds at small sizes.
- Hotspots from upstream's `HOTSPOTS` (500 px units); left-handed variants mirror them (`500 - x`, as upstream's
  `svg/LeftHanded/HOTSPOTS` does for every Windows role).
- Animations as upstream: one element rotated per frame about its own centre - busy 36 frames, working 24 frames,
  help 2 frames (2 s upright, 0.5 s turned); 50 ms per frame (Windows: 3 x 1/60 s, exact).
- Windows role mapping incl. Pin and Person (both use the pointing hand). Move uses upstream's open hand
  (`all-scroll`): Comix has no four-way arrow. No files in overrides/.
